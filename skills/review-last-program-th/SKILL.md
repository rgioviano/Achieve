# Review last program (TrainHeroic)

**When:** Before writing a new Achieve program draft for an athlete or adult client. Do this **first** - before exercise selection or Programming-room posts - so you know the last published calendar block and what to progress from.

**Input:** `{athlete}` - full name as it appears in TrainHeroic (demo typed `jacey chen`).

**Assumes:** Signed in to TrainHeroic coach on this computer’s Chrome (Achieve org). Do not enter credentials; if login is required, stop and ask Ryne.


## Default (locked 2026-09-08)

**Do not open TrainHeroic in the browser** for programming drafts unless Ryne explicitly asks.

Preferred: Ryne opens the last program on screen (like Paige) or pastes Day 1 / Day 4. Read that, note exercises/sets/reps/loads, then draft.

Only use the browser steps below if he says to pull it yourself.

## Steps (only if Ryne asks you to pull it)

1. Open TrainHeroic coach (often lands on `https://coachapp.trainheroic.com/`). Go to **Athletes** in the left nav → **My Athletes** (`https://coach.trainheroic.com/admin/coach#/athletes` or `#/athletes`).
   - Group: All Athletes (fine as-is).
   - Status: **ACTIVE**.

2. Click the **search** (magnifying glass). Type `{athlete}`. Open the matching row.

3. On that row, click the **calendar** icon (“Athlete’s Calendar”). URL becomes `https://coachapp.trainheroic.com/athlete/{id}/{year}/{month}` (demo: athlete `2788872`).

4. Find the **most recent published program on the calendar**:
   - Review the **current month** first - note the latest session titles (e.g. Week 4 Day 1 / Day 4) and any empty days after them.
   - Click the **left chevron** next to the month header to open the **previous month** and confirm the full block / earlier weeks if needed.
   - Click **TODAY** to return to the current month if you left it.
   - The last published week is the latest calendar sessions that still have a real program (not empty days after).

5. Record for the draft (Programming or the asking chat):
   - Athlete name + TrainHeroic `{id}` from the URL
   - Months checked
   - Latest week labels (e.g. Week 4 Day 1, Week 4 Day 4)
   - Exercises with sets/reps/loads when visible
   - Prep/breathing to carry (e.g. Left AIC/Right BC, SMR - Swimming)
   - Primaries to keep vs rotate next block

6. **Then** Hawkin (athletes) and program design. If the calendar is empty, say so - don’t invent a prior block.

## Do not
- Assign, edit, clone, or publish in TrainHeroic unless Ryne names the person and says to.
- Constrain Achieve to New Trier / thin gear.
- Skip when Ryne already pasted the last program screenshot - use that as the prior block; open TH only if calendar placement/date is unclear.
