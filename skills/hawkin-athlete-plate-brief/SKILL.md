# Hawkin athlete plate brief

Default template for every Achieve athlete plate brief / Coach handoff. Curve shape stays king. Never invent a metric that is not on the test. Document jump-height method continuity (Hawkin `Jump Height(m)` to Hawkin is fine; do not mix ForceDecks FT without labeling).

## Always include (analysis)

1. **Session-best** of recent trials (not a noisy mean), test date(s), n, body mass if used for relative metrics.
2. **Trend first (locked 2026-10-02):** Lead every brief with jump-height **direction**. Use only **higher / lower / plateau** (with dates) - never “soft,” “hard,” “soft day,” or “hard day” for jump output. Compare latest session-best to recent days and own peak (~4-6 week window when available).
3. **Swimmers (locked 2026-10-02):** Treat **SJ as at least as important as CMJ** - usually more so (starts/turns = concentric). Always report both when both exist; call SJ trend separately with higher/lower/plateau + dates; EUR when same-day both. Do not CMJ-only a free/fly/back/breast athlete.
4. **Curve shape** (propulsive) from the force-time skill - Early/Late Peak, Unimodal/Bimodal/Plateau, or Inconsistent.
5. **Core numbers** with units: Jump Height(m) [note Hawkin CMJ height], EUR if SJ exists that day (best CMJ / best SJ), phase times that matter (unweight / brake / propulsive or TTT/contraction time), L/R only when available and decision-relevant.
6. **Mundy strategy block (locked)** - four lines, short:
   - **Strategy:** deep-slow vs shallow-fast vs mixed - from countermovement depth + propulsive force and time. Same height can need opposite work.
   - **Height × TTT:** jump height + time to takeoff (or contraction time). Say long-TTT vs short-TTT vs their own baseline.
   - **Relative propulsive force × propulsive time:** when both exist on the test. Prefer this over impulse alone for “more force vs more speed through the push.”
   - **Braking and/or P1:P2 only when they change the week:** peak relative braking (or brake quality from curve + brake time) if the stop is the limiter; P1:P2 Propulsive Impulse Index if propulsion is front-loaded vs back-loaded. **Omit** if nothing actionable.
7. **Limiter → this-week interventions** (plate-driven, Achieve exercise language). Hand full programs to Coach (`5d64c948-3315-41b3-b9a6-196b4d1e2072`), who writes them in chat with Ryne. Strength Coach is deleted; never send to it.
8. **Asymmetry** as its own flag when real - never bury it inside the strategy line.

## Private handoff shape (locked 2026-10-02)

Coach's wrap uses a **Force Plates** section. The private note to Coach must be paste-ready under that header - plain bullets, not a long report dump:

```
Force Plates
- Trend: CMJ higher|lower|plateau (date → date, inches); SJ higher|lower|plateau (date → date, inches)
- Main finding
- Main finding
- … (flex count)
- Programming recommendations based on findings:
  - …
  - …
```

For swimmers, put **SJ trend and latest SJ** in the findings (not a footnote under CMJ).

**Main findings** = decision-relevant plate facts (date, session-best CMJ/SJ/EUR/RSI as needed, curve tag, strategy/height×TTT or force×time that changes the week, asymmetry only if it flags). Plain English; numbers with units.
**Programming recommendations** = plate-driven only (unload vs load, ISO→jump, get-down vs brake work, contact dose, what *not* to program from the curve). Do not write the full program. Jump-dose language: “quality / fewer contacts / unload” - never “soft day” / “hard day.”

Optional detail (curve landmarks, trend table) can sit below the paste block for Coach if useful - the paste block comes first.

## Do not put on the default brief

- Full FTO metric dump / seven-determinants list
- Universal fatigue % thresholds (population-specific; only when a readiness call is asked)
- Invented IMTP/DSI without both tests
- Fixed exercise mandates from Mundy (he did not give them)
- Framing jump-dose gates as “new lifter” when training age is known - dose from plates + quality limits
- Latest-only reports with no trend line
- Soft/hard jump-day language (use higher / lower / plateau + dates)

## Delivery

- Normal athlete ask: Send the Force Plates paste block (+ short limiter note if needed) privately to Coach (`5d64c948-3315-41b3-b9a6-196b4d1e2072`) (priority true). Strength Coach is deleted. The handoff counts as delivered only when Coach confirms. Do not post the plate report into a shared room unless Ryne @-mentions Hawkin.
- Numbers with units and dates. Physics first, then prescription.
