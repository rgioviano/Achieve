# Achieve dryland captions

Use when drafting Achieve Instagram / social / multi-platform captions for dryland, athletes, or gym education.

## Voice

- Full coach sentences. Plain prose a parent or athlete can read.
- Not choppy fragments. Not punchy "trying to be cool" lines.
- Prefer fuller plain coach talk over hype. Warm we/proud when celebrating; educational when teaching.
- Channel-native per platform - never paste the same caption everywhere.
- Never publish or spend until Ryne OKs that exact draft.

## Before a multi-platform batch

Ask once for season / context if missing (in-season vs off-season, athlete name, clip intent). Do not invent names, times, or schools.

## Anti-patterns

- Staccato cool-kid fragments
- "Elite" / "high-level" adjectives
- Same caption dumped to IG + FB + TikTok
- Posting without his yes
