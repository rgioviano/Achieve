## 1. How PRI Non-Manual programs are organized

Introductory courses each have Non-Manual CDs organized by **muscle, inhibition, and integration**, ordered by how you would isolate → inhibit → integrate. Integration program: 300+ techniques across nine positions; Integration symbol = thorax–pelvis via abdominals (**inhibit a pattern / facilitate a position** — not "strengthen abs").

**Reference centers (Integration):** left abdominals, left ischial seat, left heel, right arch.

### Terminology in titles
| Term | Meaning |
|---|---|
| Respiratory | Phase of respiration that expands L posterior mediastinum, L posterior outlet, or L posterior hip capsule |
| Reciprocal | Full available ROM both directions |
| Alternating | One side then the other (e.g. 3 breaths L then 3 R) |
| Supported | Proprioceptive surface (wall, floor foot, pillow, table) |
| Resisted | Band |
| Weighted | Free weight |

### Hard progression rules
- Neuro-motor position order follows Integration demand (exceptions: R Glute Max differs Myo vs Pelvis; Inhibition programs; R Low Trap/Tricep order on Postural CD).  
- **Bilateral inhibition always precedes unilateral.**  
- If a technique "looks in the wrong muscle folder," assume intentional facilitation via inhibitory muscle/position/process — don't reshuffle by bodybuilding logic.  
- Example: 90-90 Supported Hip Lift with Hemibridge **always** precedes 90-90 Hip Lift with Balloon.

### Why BC muscle order is R LT/Tricep → L LT/Serratus → R Serratus → R Subscap
Typical L AIC + R BC: pelvis/spine/diaphragm oriented right; thorax rotates back left above diaphragm for frontal balance and R reach. Right-handedness promotes that left upper rotation and disadvantages R low trap / triceps / serratus.

1. **R low trap + tricep** — retract/posterior-tilt scapula; stabilize spine with L abs; elbow extension; thoracic flexion; lat down.  
2. **L low trap + L serratus** — reorient upper thorax; stabilize upper quadrants during R reach.  
3. **R serratus** — stabilize R scapula for R reach **without** needing left upper trunk rotation.  
4. **R subscap** — HG IR independent of overactive lat (after neutrality).

Later positions in each muscle set demand **more isolation with more substitution inhibition**.

## 2. Position decision-making (advantages)

| Position | Best for |
|---|---|
| Supine | Bilateral sensory comparison; ANS outcomes (SLR); cranial–pelvis sagittal tilt; early facilitation |
| Sidelying | Best **non-dominant unilateral compensatory inhibition** |
| All Four | Flexed appendage co-activation during thoraco-abdominal flexion; best respiratory position |
| Short Seated | Best passive reposition |
| Long Seated | Best desirable position to strive for and maintain |
| Seated | Thoracic–pelvis rotation without thoracic–cervical hyperactivity |
| Standing | Re-biasing alternating lateralized cortical / centering sense |
| Prone | Inhibit L TFL via L FA IR |
| Kneeling | L glute med isolation with hamstrings shortened |

## 3. Course positional outlines (families to open)

### Myokinematic Restoration (examples of muscle folders)
Left Hamstring → Left IC Adductor → Right Glute Max → Left Glute Med → Left Hip Flexor Inhibition → Left TFL Inhibition → … (position ladders: supine → sidelying → long seated → seated → standing → all four → prone as listed per muscle).

### Pelvis Restoration
Right Rectus Femoris/Sartorius, Left Obturator/Iliococcygeus, Left Iliacus, Right Glute Max (different order than Myo), inlet/outlet inhibition folders (L anterior inlet, R anterior outlet, R posterior inlet, L posterior outlet), etc.

### Postural Respiration
Right Lower Trap & Right Tricep → Left Lower Trap & Left Serratus → Right Serratus → Right Subscapularis; plus Paravertebral / Pectoral / Lat / Intercostal / Anterior Neck inhibition families.

Open the matching course skill for test gates (ADT/PADT, apical, etc.) before picking a folder.

## 4. Workshop technique cards (from typed notes — Achieve-usable)

Each card: **Reference / Referent(s)** → inhibit → who it's for → coaching notes.

### Right Sidelying Left Adductor Pull Back with Knee to Knee
- **Ref:** L post calcaneus/heel (low). **Referents:** L IO/TA (high), R med long arch (low).  
- **Inhibit:** R thoracic diaphragm (by empowering left); L post outlet / L ant inlet / R post inlet / R ant outlet; L posterior ground with R forward movement; L rearfoot with L abs + R forefoot (late double stance → left shift).  
- **For:** difficulty rotating upper trunk R while lower trunk left; need left "load" to free R arm/chest (static/overtight right).  
- **Cues:** Push L hand into floor → R trunk rotation with L AF IR (L IO/TA). Sense leftward retro. Lower upper body to floor before going vertical. Also inhibits L short FA ERs, R short AF IRs, R short back rotators (R QL, R IO/TA).

### Left Sidelying Foot Toward Ceiling with Resisted Right Glute Max and Right Apical Expansion
- **Ref:** L ischial seat (mod), R med long arch (low). **Referents:** R lat post upper chest (R LT/triceps), L ant AF capsule (L adductor), L IO/TA, R post hip (R glute max).  
- **Inhibit:** Overuse R IO/TA/EO + R rectus; R BC; R hip flexor (psoas+TFL); TF ERs; R intercostals.  
- **For:** sense of left / shift left; R thoracic curve; R mouse/computer; R shoulder impingement; interscap pain / flat backs; limited R cervical lateral flexion; post R subclavius release.  
- **Cues:** L HG ER (teres minor/infraspinatus) helps posterior mediastinal expansion and forces R apical up; cross-ref anterior rib abs with posterior scapular stabilizers + SA.

### Stair Short Seated Balloon
- **Ref:** L ischial seat. **Referents:** L IO/TA, L post calcaneal tuberosity, R med long arch, L post mediastinum, R lat post upper chest.  
- **Inhibit:** R hemilateral foot/ischial/ZOA "grounding"; lat / longissimus / interscap; quads.  
- **For:** unsteady left foot / can't pause without leaning back-right; wide BOS gait; can't squat from short quads/hip flexors.  
- **Cues:** Best position to establish posterior mediastinums **and** upper lateral chest expansion on inhale **and** exhale; prep for retro / cranio activity.

### Long Seated Press Down
- **Ref:** R lat post upper chest (R LT/tricep) R>L; L post heel L>R. **Referent:** L IO/TA L>R.  
- **Inhibit:** Hip and neck flexors via hamstring–tricep cross-reference.  
- **For:** protracted shoulders + deep lumbar curve; periscapular weakness; bicipital tendinitis; sitters who overwork rectus + anterior chest/neck.  
- **Cues:** Awareness of 90° SLR with neutral thoracic orientation; balance mid/lower trap, SA, rhomboids, subscap with tricep; enhances subscap/SA with abs + dorsiflexion.

### Seated Supported Respiratory Left AF IR/FA IR with Intercostal Pulley Inhibition
- **Ref:** L ischial tuberosity. **Referents:** R LT/tricep, L ant AF capsule (adductor), L IO/TA, R med long arch.  
- **Inhibit:** R IO/TA; R upper trap; R scalenes/BC; R intercostals; L TFL; patterned inlet/outlet set; R posterior mediastinum; L levator.  
- **For:** poor R overhead reach sitting/standing; can't reach up/out while turning upper body same side.  
- **Cues:** Sense L adductors + L glute med/min during L posterior mediastinum + R apical expansion; pelvic/hip anchor for contralateral release.

### 90-90 Supported Wall Leg Lift with Alternating Resisted Arm Reach
- **A ref:** L heel; referents R glute max, L IO/TA, L post mediastinum.  
- **B ref:** R heel; referents L glute max, R LT/tricep, L post mediastinum.  
- **Inhibit:** A = L AIC/R BC; B = L low-back extension + L LT/triceps.  
- **For:** dissociation issues; poor ground friction sense + scapula-on-thorax friction; flat back / flat affect / rigid.  
- **Cues:** Alternating secures LE for ipsilateral lower torso rotation + contralateral upper torso rotation **without** cervical help; intro to retro; both pictures get L posterior mediastinum (A via L SA + L hammies; B via R SA + left leg lift).

### Right Sidelying Left Anterior Glute Med with TFL Inhibition
- **Ref:** L ischial tuberosity. **Referents:** L IO/TA, R glute max.  
- **Inhibit:** L TFL; R hip adductors; L rectus femoris.  
- **For:** poor L single-leg strength (step overs/throughs); flat L feet / don't know how to pronate.  
- **Mods:** Ball between knees → more ant glute med/min; bolster under R ankle → more R FA ER vs abd; light weight on L ankle → more L glute demand.

### Left Sidelying Supported Trunk Lift
- **Ref:** L IO/TA, L heel. **Referent:** R LT/triceps.  
- **Inhibit:** R calcaneus; R ischial seat; L canines / R molars; L post hip; L LT/triceps (+ R bicep/pec); R ant AF capsule; R IO/TA.  
- **For:** vestibular leftward figure-8 difficulty; Superior T4; L hemidiaphragm weakness/SOB; clenchers; post MMOO/MOOO orthotic.  
- **Cues:** Pillow under pelvis aligns pelvis–cranial bowls; wall anchors feet for torso–pelvis–cranium axis.

### Seated Resisted Reciprocal Pull Downs
- Keep upper trunk turned right. A emphasize inhale; B emphasize exhale.  
- **Inhibit:** A = L upper trap / L apical / R BC; B = R upper trap / R abs / L anterior BC.  
- **For:** retrain alternating trunk with L pelvis/hip security; cervicalgia / temporal-frontal HA.  
- Lower chair → more heel / ischial / ST / OA extension R>L demand.

### Single Leg Stance with Contralateral Glute Max
- Block under foot = hemi vestibular-postural demand; pole in R hand for balance / compression bias.  
- **Inhibit:** A = back extensors esp R QL/paravertebrals; B = L pec minor.  
- **For:** A LBP / weak quads / overused L VL; B L AIC reposition / weak L FA IRs in hip extension.

### Standing Supported Bilateral IO/TA
- **Inhibit:** glossopharyngeal, tongue, shoulder elevators, upper traps, lats, plantarflexors.  
- **For:** forward head; sleep apnea; laryngeal tension; swallowing issues.  
- **Cues:** Retro BOS sense; Functional Squat Test ≥3 allows abs to rotate torso; arms overhead with eccentric hammies/adductors; intro R then L arm reach.

### Standing Left Knee Flexion with Right AIC Progression
- **Inhibit:** latero-spatial single-leg transfer sense; hip flexors; R quads.  
- **For:** SLR >90° bilaterally (abs as rotators, hammies stabilize); LBP/SI; limited L shoulder flexion (pulls L thorax under L scapula); R tennis elbow from over-supination; R quad overuse.  
- Ground sense lifts on **left** secondary to R UE extension position.

### Standing Supported Left Glute Push
- Valsalva-like between exhale and inhale without balloon/nose pinch; lift R LE → R psoas + R FA ER to keep mass left.  
- **Inhibit:** anterior neck / scalenes / accessory respirators.  
- **For:** autonomic dysfunction / dysautonomia (see PRI Breathing Mechanics in COVID Times week 3 handout referenced in notes).

### Modified Two Point Gait with Left AF IR
- Poles slow pelvis timing vs scapular alternation; R pole lever with R triceps → R LT + pelvic floor for L AF IR cognition.  
- **Inhibit:** ipsilateral UE–LE ambulatory pattern (R UE with R LE / L with L).  
- **For:** ataxia; scissor gait.

### Standing Right Knee Flexion with Resisted Left Hamstring and Right Trunk Rotation
- **Inhibit:** L hip flexors; R SCM; R BC (pecs); R hip adductors; L trunk rotation / R IO/TA.  
- **For:** R PF pain / quad tendinitis; R LE centering during L hip adduction; bilateral lat / back-over-extension users.  
- Mimics resisted decline retro walk (L abs; R floor back / R foot forward during L hip extension).

## 5. When to open which family (coach decision map)

| Goal / finding | Start family |
|---|---|
| Need ZOA / L AIC inhibition / balloon | 90-90 family, Stair Short Seated Balloon, Wall Supported Squat Balloon |
| Need L AF IR + R freedom | R Sidelying L Adductor Pull Back; Seated Respiratory L AF IR + intercostal pulley |
| Need R apical + shift left | L Sidelying Foot Toward Ceiling + R glute max / R apical |
| Need PEC / paraspinal down | Stair Short Seated Balloon; Standing Supported Bilateral IO/TA; Paraspinal inhibition folder; Functional Squat families |
| BC tests − → R LT/tricep | Long Seated Press Down; Seated/Standing Alternating Tricep Pulldowns; Sidelying Trunk Lift R |
| Need L serratus stabilize | 90-90 Wall Leg Lift Alternating Reach; Standing Serratus Squat; All Four Belly Lift Reach |
| Need true R HG IR | R Subscap folder **after** neutrality (not lat IR) |
| Single-leg / gait | Single Leg Stance Contralateral Glute; Modified Two-Point Gait L AF IR; Standing R Knee Flexion + L hammie |

Always re-test course screens after a technique block.

## 6. What NOT to do

- Cherry-pick "cool" late positions (prone/standing isolations) before early ones work.  
- Unilateral inhibition before bilateral.  
- Cue techniques as ab hypertrophy or generic mobility.  
- Ignore reference/referent sensing — without tactile co-reference the neuro outcome weakens.  
- Skip course test gates and jump folders by symptom name alone ("shoulder" → random serratus).

---

## 7. Achieve programming translation

- Warm-up: 1–2 repositioning techniques from the map (often 90-90 balloon or stair short seated balloon + one sidelying).  
- Tertiary: match folder to remaining test (R LT/tricep vs L serratus vs inhibition).  
- Write **reference sense** in athlete cues ("left heel + left abs," "right arch," "left sit bone").  
- Swimmers: bias Stair Short Seated Balloon / Wall Reach / All Four Belly Lift Reach / R apical sidelying + later R subscap only after BC neutrality language.  
- Keep clinician manuals (Superior T4, Subclavius, Infraclavicular) out of gym improvisation — see Right BC guidelines skill.
