## Always-on swimmer rules

1. **Scapulae / neck**
   - R scapula → R lower trap + R triceps
   - L scapula → L serratus (depression / protraction / rib-cage retraction)
   - Every program needs a **squat-and-reach** somehow (seat scapulae on rib cage, quiet neck). Cue **reach forward, not shrug**.
     - Wall supported reach → band-resisted wall reach → squatting bar reach → squatting bar reverse reach
   - UT / neck inhibition: rib-cage IR, SCM balance

2. **Streamline triad** (fly, breast, sprint free, UW): full **shoulder flexion + hip extension + plantar flexion**. Normal PF ROM **40–50°**. Much "toe point" = **midfoot flexion**.

3. **Catch pain** = over-active lat + under-active subscap. Impingement theme: better **R triceps + L ZOA**, lat inhibition, rib expansion, **R HG IR** (R scap retraction).

4. **Straight-arm press down** = key for fly + free. Straight-elbow shoulder extension helps all strokes.

5. **Rolling + rotation:** MSR (and lumbar-locked rotation / ISA as needed). **Prone↔supine rolling** is a primary corrective for free + back body roll. Back needs ~**30°** roll relative to water.

6. **Core:** ~**2** core exercises per workout across the 4 categories; progress toward stability **with moving limbs**.

7. **In-season / within 2 weeks of a key meet:** minimize slideboard/glider + eccentrics; favor concentric; **no new exercises** (soreness).

8. **Season shoulder math:** IR strength rises more than ER over a season → IR:ER drifts. Bias ER / scap control and don't only feed IR. (JSR: high-school swimmers over a competitive season.)

## Volume bias by stroke / event

| Population | Loading / volume bias |
|---|---|
| Fly | Less bilateral; **upper > lower** volume likely; still train legs for kick/starts/turns |
| Back | More bilateral; **upper > lower** likely; slightly more leg than free (kick volume) |
| Breast | Less bilateral; **upper ≈ lower** (kick-driven but multi-event athletes) |
| Free sprint | More bilateral; **legs + jumps priority**; more RT volume than distance |
| Free distance | More bilateral; **upper > lower** likely; endurance / circuits; connecting U+L |

## By stroke (prescription lens)

### Butterfly
- PF/DF screen; glutes + leave bilateral extension (sagittal / QL / lat inhibition) if dolphin LBP
- Straight-arm press down; prone HA via **swimmer hovers**, HA ball drops, functional squat w/ low trap

### Backstroke
- Trunk rotation for deep catch (palm down); R HA (L if needed) via:
  - L sidelying resisted serratus punch + R trunk rotation
  - L sidelying L flexed FA adduction + R glute max + R trunk rotation
- Rib integration / sidelying Swiss ball + R apical expansion for roll
- Watch pull-phase hyperextension / anterior glide / impingement

### Breaststroke
- Tall kneeling core (OH reach, anti-rotation, MB OH throws) for straight-hip + stability
- **PADT negative bilaterally** required for breast kick - else ipsilateral LBP / knee / groin
- Knee flexion **with straight hips**: Swiss ball / slideboard / TRX curls, Nordics, GHD, SHELC
- Breaststroker’s knee often **missing hip IR** → IR-bias SL squat etc.
- Assess: hip IR/ER, extension + adduction drop, prone hip ext, PF/DF

### Freestyle
- Full hip ext without lumbar cheat (prone table); PRI all-4 SL R glute max; leave extension posture
- Trunk rotation for DPS / early catch / high elbow; R HA (same L-sidelying pair as back)
- Neck rotation for bilateral breath (L abs + R chest wall themes)

**Sprint free:** kick + vertical/horizontal jump culture (starts/turns ~leg-driven); less shoulder roll than distance; own top speed in first 2 strokes (straight-arm extension); higher RT volume; streamline.

**Distance free:** more shoulder roll / stroke length; endurance over max strength; lower volume; TGU / contralateral offset connectors; triceps may matter for reach-glide rhythm.

## Starts

- Spinal flexion to grab block: toe touch; PEC / paraspinal inhibition (often pairs with limited OH for streamline)
- PF + **first ray** strength matter
- Horizontal / split-stance power bank: staggered broad jump (± band); weighted squat jump (± bands); split-stance weight slides (arm drive); GHD; DB step-up jump; staggered trap-bar DL; staggered BB hip thrust; KB swing as horizontal option
- Explosive split-stance: sandbag hang clean → step/box; trap-bar high pull; 1-arm DB snatch ± step; SL RDL → hang clean; rotational reverse lunge → hang clean; sled 1-push / multi / jump from split
- Backstroke start: MB OH scoop toss or scoop behind
- FFE split stance broad / box jump; box jump with front foot on DC blocks

## Turns

- Push-off knee **110–120°** (SSC): mid-pause squats, paused box jumps, heavy partials in that range, hurdle / depth jumps, bands/chains
- Compact flip = spinal flexion (same PEC/toe-touch theme as starts)
- Season: full-depth early → bias **½ squat / 110–120°** closer to championship meets

## Underwater / kick

- +10° PF ≈ +16 N on dolphin downsweep (~66% peak force at feet)
- UW breath-hold often limiting; deep pre-race breathing may help 50/100 free
- Strong up-kick = glutes + hammies; GHD useful for starts + kick

## Shoulder pain menus (PRI-named)

Full Advanced Integration banks: [PRI shoulder pain prescription](sand-workflow:pri-shoulder-pain-prescription). Short Achieve list below.

**General shoulder pain**
1. Lat hang (standing lat inhibition 1)
2. L sidelying weighted R HG HA + R FA ER (R low trap / R triceps 4) - R scap retraction + L IO → R HG IR theme
3. Supine resisted R HG IR + L HG ER (R low trap / R triceps 16) - R towel wedge, towel under L elbow; keep L ZOA/PME/IO
4. L SL resisted R HG IR (R subscap 2) - L ZOA + L trunk rotation + R HG IR

**Impingement:** abs exhale + stay contracted on inhale (rib expansion); lat inhibition; R low trap + R triceps.

**Biceps tendonitis:** R upper trunk rotation; R apical expansion; R subscap + lat inhibition. Same L sidelying serratus punch + R trunk rotation as HA driver.

**L shoulder pain (often MDI):** treat as bilateral / longer course. After repositioning → L posterior mediastinum expansion (reach + L abs); may need L pec inhibition. AF belly lift reach; modified AFBL pad under L hand; long seated alternating crossovers; AF belly lift.

**Long seated supported press downs** (R iliacus/psoas **or** abs) - useful when UT / FHP / bicipital / rounded shoulders / flat back / tight calves / anterior scalenes themes stack.

## Dryland performance screens (optional standards)

Candidate weakness map: front squat velocity, **1RM pull-up**, trap-bar DL, **non-CMJ**, standing broad jump.

Published protocol notes: pull-up 1RM; back squat velocity @ **½ BW** to hip-crease-below-knee (rope depth), Tendo average concentric m/s; non-CMJ with **1s pause** at depth.

Use as **screens**, not automatic auto-gates - individualize to training age and season.

## Quick decision tree

1. Stroke / event + season → volume bias + in-season constraints  
2. Pain? → shoulder menu / PADT (breast) / extension posture before loading more pull  
3. Starts/turns/UW priorities this block? → horizontal/split power + 110–120° + PF/first ray  
4. Always include squat-and-reach + 2 core; add rolling/rotation for free/back  
5. Pair FRC swimmer hovers / HA when end-range ownership is the limiter; pair PRI breathing when ZOA / roll / neck is the limiter
