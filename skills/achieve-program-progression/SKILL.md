# Achieve program progression

**When:** Before writing a new Achieve program draft. Use this **with** [Review last program TH](sand-workflow:review-last-program-th) (calendar = where they left off) **and** Asana + Hawkin. This skill teaches *how Ryne progresses* across published library blocks - not only the latest calendar week - so drafts read like he wrote them.

**Input:** `{athlete}` - name as it appears in TrainHeroic titles. Parent/guardian TH names still apply when different (e.g. Avery → Brianna Lantz).

**Assumes:** Signed in to Achieve coach Chrome on this computer. Do not enter credentials. Read-only - do not edit, clone, assign, or publish.

## Categorize the person

- **Difficulty** shows as Beginner / Intermediate / Advanced tags on Library rows (also in program settings).
- **Adults / general clients:** gear icon → **Sport/Focus Interest** = **General Fitness**.
- Athletes: Sport/Focus Interest is the sport (e.g. swimming); use difficulty tag for level.

Short library chains are fine - learn from whatever history exists (no hard 10-program floor).

## Steps

1. Open **Library → Programs**: `https://library.trainheroic.com/`.

2. Search `{athlete}`. List programs in date order (titles usually `{Name}ProgramMM.DD.YY`).

3. Open consecutive programs newest → older (as many as useful, up to ~10). Prefer full sessions, not stubs.
   - Open via program title → `https://coachapp.trainheroic.com/program/{id}` (Library row IDs ≠ coachapp program IDs - confirm from URL).
   - Capture Week 1 (and skim Weeks 2–4): Day 1 and Day 4 when those labels exist; else the person’s day labels (e.g. 1/3/5 or 1/3/5/6).
   - Note: prep / breathing / movement prep; power; strength pairs; core / tertiary / finish; start loads; what changes week to week.

4. Infer **within-block** and **block-to-block** rules (write them before drafting).

5. Apply those rules to the next Programming-room draft (house sheet titles; ≤1–2 primaries kept; single start load in chat drafts unless Ryne asks for Wk 1–4 lines).

## Ryne progression language (learned from Library)

Sampled: Alyssa Shields, Annika Anderson, Brayden Capen, Annabelle Nawrocki, Braden Meurer, Alex Parkinson, Carla Schwartz, Deb Wright (General Fitness adults).

### Within a 4-week block
- **Exercise menu stays the same** across Weeks 1–4. Do not invent weekly exercise rotation inside one published block.
- **External loads usually stay fixed** for the block.
- Progress **reps, hold durations, and core density** - not load chase every week.
- **Week 4** commonly **deloads volume** (fewer sets/reps or shorter holds) while keeping the same exercises and loads.
- Prep (SMR + breathing + movement) and finishers (90/90, wall seated-reach / repositioning, deep-squat breathing) **repeat daily** inside the block.

### Athletes (Beginner → Advanced)
- Sport-specific SMR + ISA/PRI breathing (e.g. Left AIC / Bilateral BC for many swimmers).
- Power early: jumps, snap-downs, drops, sprints/shuffles, med-ball throws/slams - scale intensity with level (hurdle/depth height, MB weight, hang clean / complex primers at Advanced).
- Strength: heavier bilateral + unilateral pairs; chin-ups / landmine / trap bar / SSB common as level rises.
- Beginner/land: more assisted or lighter unilateral; still has reactive/power slots.
- Intermediate/Advanced swim: denser power + higher absolute loads; day labels may be 1/3/5 (no Day 4).

### Adults (General Fitness)
- Emphasize breathing, positional control, trunk, carries, general conditioning (Ski Trainer, step-ups, etc.).
- Less jump/sprint menu than athletes; more landmine/KB/cable/TRX and anti-extension/anti-lateral work.
- Same within-block rule: fixed loads, progress holds/reps, Week 4 volume cut.

### Block-to-block (next published program)
- Preserve **movement families**, not necessarily the exact exercise: squat, hinge, vertical pull, unilateral, jump, med-ball power recur while **variants rotate**.
- Keep ≤1–2 primary strength *patterns* continuous when it fits; change nearly every other slot (power rotates freer than strength).
- **Across blocks, reset load for the new variant** - do not force a linear climb off the previous exercise’s number. Progress that variant on its own after the reset.
- Pull-up/chin-up load sometimes carries (e.g. +20 lb across blocks) when the family stays; lower-body loads often reset with the variant (SSB box ↔ front squat ↔ Hatfield, etc.).
- Jump height / med-ball weight change modestly; exact jump and throw type rotate often.
- Advanced: heavier loading and more isometric/contrast primers - not guaranteed linear load increases block to block.
- Carry forward breathing/ISA theme and constraints (no true OH for overhead athletes, equipment, injury notes).
- Lateralize patterns rather than random swaps (e.g. RFESS → reverse lunge; hip thrust ↔ RDL/trap bar when constraints demand).

## Report shape (short)

- Programs reviewed: titles + coachapp ids + dates (newest → oldest)
- Within-block pattern (menu / load / Week 4)
- Block-to-block keep / rotate / load notes
- Athlete vs adult cues that apply
- Implication for next draft (1–3 bullets)

## Do not

- Assign, edit, clone, or publish in TrainHeroic unless Ryne names the person and says to.
- Invent exercises not on the Achieve progression sheet (power/breathing may come from prior TH / house templates).
- Weekly-rotate exercises inside a single 4-week block when matching his published style.
- Encode CDP ports, Playwright, or harness internals in this recipe.
