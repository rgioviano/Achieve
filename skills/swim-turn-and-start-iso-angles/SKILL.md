# Swim turn and start ISO angles

Locked 2026-09-14 from S&C Research (Araujo 2010; Maglischo; Slawson 2012 OSB11; breast open-turn means).

Swimmers need **turn or start** angles for pool transfer - not a typical land-sport jump depth.

## Two tools (do not mix them up)
1. **CMJ / land plates** → put the ISO where force dips on *their* curve (often ~quarter squat for early bimodal hang).
2. **Pool transfer** → use the turn or start angles below.

Do **not** default every swim ISO to a land quarter squat when the goal is the wall or the block.

## Flip turn (wall push)
- Knee at plant: about **100-120°** (Araujo 2010; Takahashi peak ~120°)
- Hips: about **90°** flexed (Maglischo)
- Too tucked → long wall contact; too straight → weak push

## Open turn (breast / fly)
- Thinner data
- Breast open turns often about **108-112°** knee mean
- Coaching target about **90-120°** knee

## Start (kick / track block)
- Rear knee about **80-90°** for peak vertical force
- Rear knee about **100-110°** for peak horizontal (Slawson 2012 OSB11)
- Many fast starts near about **80°** rear knee
- Keep hips relatively open

## Achieve use
- Breaststroker open-turn ISO ≈ **100-120°** knee
- Freestyle/back flip-turn ISO ≈ **100-120°** knee, hips ~90°
- Start ISO → pick rear-knee band from the intent (more vertical vs more horizontal)
- Name the tool in Direction: plate-dip ISO vs turn/start ISO

Breaststroker example (2026-09-14): plate dip still = quarter-squat `Split Squat ISO Push`; swim-transfer ISO later ≈ 100-120° knee for breast open turn.
