# Program Design Basics

Source (Ryne Gioviano):  
`/home/box/agent-data/shared/sc-reference/program-design-basics.txt`  
PDF: `/home/box/agent-data/agents/0c56f311-56b5-4ded-ae36-22f03da7a160/memory/reference/program-design-basics.pdf`

Cook vs chef: new coaches follow this recipe until told otherwise. ~1-hour sessions. Deviate only when earned / instructed.

## Session order (fatigue high → low)
1. Self-myofascial release  
2. Breathing / PRI  
3. Warm-up  
4. Speed  
5. Agility  
6. Upper/lower body power  
7. Knee-dominant (bilateral then unilateral as programmed)  
8. Hip-dominant  
9. Horizontal push / pull  
10. Vertical push / pull  
11. Anti-extension → anti-lateral flexion → anti-rotation → hip flexion w/ neutral spine  
12. Accessory / scapular stability / rotator cuff (tertiary)

## Speed & agility
- Fresh only: after warm-up, before power/strength. Max intent every rep. Long rest.
- Categories: linear, lateral, COD, deceleration.
- Swimmers: land speed for RFD / reaction; sport speed mostly in water.

## Power
- After speed, before strength. Non-competing pairs (usually LB + UB). High intent, full recovery.
- LB vertical / horizontal / lateral; UB overhead / rotational / horizontal.
- Example Day 1: Standing Broad Jump + Tall Kneeling MB Slam. Day 2: CMJ + ½ Kneeling Rotational Scoop Toss.
- Swimmers: bias lower-body **horizontal** power. Land athletes: include lateral when sport needs it.

## Strength pairings (2-day house)
**Day 1:** B1 bilateral knee-dom + B2 pull; C1 unilateral hip-dom + C2 push.  
**Day 2:** B1 bilateral hip-dom + B2 push; C1 unilateral knee-dom + C2 pull.

Rules:
- Knee-dom with pulls; hip-dom with pushes (lats stabilize hinges).
- Prefer unilateral over stacking two bilaterals. Day 2 is the inverse of Day 1 (if Day 1 had bilateral UB push, Day 2 is unilateral UB push).
- **Overhead athletes: no true vertical press.** Closest = landmine / DB incline / overhead holds. Limited shoulder mobility → same rule.

## Core (non-competing)
Categories: anti-extension, anti-rotation, anti-lateral flexion, hip flexion w/ neutral spine.  
Good pairs: AE + ALF or AR; ALF + AE or hip-flexion.  
Avoid: AE right after hard push-ups; AR right after unilateral presses (already anti-rotational).

## Tertiary / accessory
Knee flexion, plantarflexion, ankle eversion/inversion, late PRI, cuff, scap work, needs-based fillers.  
Often D1/D2/D3 with core, or as a filler with a heavy lift (e.g. Trap Bar DL + Child’s Pose Serratus Breathing).

## Example 2-day swim template
| Day 1 | Day 2 |
|---|---|
| A1 Box Jump | A1 Standing Broad Jump |
| A2 Standing MB Slam | A2 Supine MB Vertical Throw |
| B1 BB Front Squat | B1 Trap Bar Deadlift |
| B2 Neutral Grip Pull-Up | B2 ½ Kneeling 1-Arm Landmine Press |
| C1 Landmine SL RDL | C1 DB Goblet Reverse Lunge |
| C2 Standing 1-Arm Cable Chest Press | C2 2-Point DB Row |
| D1 Standing TRX Fallout | D1 Dead Bug w/ Cross Reach |
| D2 Tall Kneeling Anti-Rotation Press | D2 Weighted Side Plank |
| D3 Prone 1-Arm Y On Table | D3 Sidelying 1-Arm DB ER |

## Weekly frequency
- **1-3x/week:** full body every session (power → strength → core → tertiary).
- **4x/week:** upper/lower split (consecutive days need recovery).

## Structure counts
- Breathing: 1-2. Warm-up / movement prep: 6-8 (eval-driven).
- Athletes ~8-9 total training exercises; adults ~6-7. Mostly supersets/tri-sets. ~1 hour.

## Sets / reps (defaults)
- Sets: **3** standard. Advanced sometimes 4-5 only when sport stress is low (off-season / early season / break). Taper: 1-2 main sets (~40-60% volume cut).
- Reps: **8** standard. Accessories up to 12. Strength meso for intermediate/advanced: 3-6 after pattern is owned.
- By slot: B1/B2 often 6-8 (adv strength 3-6); C1/C2 8-10 (sometimes 12); core D1/D2 time 20-45s or 10-15 reps; tertiary D3 10-12 (to 15).

## Deload & progression
- Blocks 4+ weeks: last week deload - drop anything >3 sets down to 3; keep intensity.
- Non-loaded / timed work: +5 seconds per week.
- Start conservative. Assessment, training age, injuries, sport, and season override defaults.

## Logistics
Start on younger athletes (11-14) and master this format before nuanced cases. Check eval results. Collaborate with other coaches.
