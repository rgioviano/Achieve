# Gmail Waiting vs Follow-Up

Use these labels correctly. They are not the same folder.

## Meanings

- **Waiting** - ball is on them. Ryne’s last send **asked a question** (or he is waiting to hear back before anything further).
- **Follow-Up** - chase pile. Quiet ~3+ days after a question send. Keep Follow-Up until he clears them or says otherwise.
- **Inbox** - reply pile (needs him this week). Do not recreate Action.
- **Later** - real but not this week, with a named future date.
- **Reference** - keep forever, no next step.
- **Archive** - done / noise. Archive alone wins as done even if Waiting / Follow-Up / Later / Reactivate remain. Never restore Inbox or re-list archived threads. Never archive client, parent, or other human threads that still need a reply; if unsure, leave in Inbox. Newsletters, Zapier, Meta, MindBody receipts, calendar noise → archive.

## Morning inbox triage (Ryne's rules, locked 2026-10-19)

Penny runs this every morning on all four inboxes: work, contact@, personal, IronBlueprint.

**Star (rare).** Star ONLY critical items with real consequences or a deadline in the next 1 to 2 weeks: e.g. Wealthfront "payment will fail", Tesla lease steps, real security alerts (new sign-in, Takeout). Never pin. Never star program generations, receipts, lead forms, or routine mail. Client AutoPay failures: mark Important and list them in the report; star only if Ryne says.

**Mark Important (no star).** Every lead form, form submission, and new inquiry ("lead forms are always VERY important"), plus mail from a real person that needs Ryne. Then archive lead forms (Tally searches archived mail). Keep human threads that need a reply in Inbox.

**Archive.** Newsletters, promos, marketing, notifications, receipts, plugin alerts, Numa/Zapier/Meta noise, WordPress "update plugins failed", password-reset requests. Ryne likes the tea newsletters (Sugimoto Tea); never list them for unsubscribe.

**Never** send, reply, or unsubscribe on your own. Suggest unsubscribes as a list; act only on the names Ryne approves.

**Report every run.** Post one line to Ryne: `Triage ran: X archived, Y starred, Z need you.` Name the Z people. If the run fails, say so in that line. Never stay silent, so Ryne never has to ask whether it ran.

## After send (locked 2026-09-19)

1. **Asked a question** → apply **Waiting**, remove **Inbox**.
2. Quiet ~3+ days on that question send → apply **Follow-Up** (chase), restore Inbox if needed for the chase list.
3. **Confirm / answer / FYI / close with no ask** → do **not** apply Waiting. Archive or leave labeled done.
4. Do **not** auto-strip **Follow-Up** from chase threads.
5. Do **not** dual-file Follow-Up on every send.
6. Do **not** sweep Follow-Up off Sent or Waiting just to clear a folder.

Supersedes the old blunt rule “after any send apply Waiting.”

## Chase threads / follow-up list

Only **suggest a chase** when Ryne’s last outbound **asked a question** (ball still on them) and the thread is quiet ~3+ days. Do not chase when he only confirmed something or answered their question. Default: short list with one-sentence “where we left off”; full draft only when he asks. Any full draft to a client, parent, or lead goes through [Pre-draft check](sand-workflow:pre-draft-check) first.

## Signature

Never type a signature into a draft body. Gmail adds it when the draft is sent, so a typed one appears twice. End the body with "Thanks," only. (Connector/API sends that bypass Gmail's signature: plain text only, no URLs, since Gmail wraps any URL into `google.com/url?…`.)

## Ownership

PA / CoS / CRM all follow this. CRM owns Lead Form sheet filing; Penny marks Lead Form emails Important, then archives them. Never auto-strip Follow-Up.
