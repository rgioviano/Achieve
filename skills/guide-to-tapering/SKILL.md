# Guide to tapering

Full source: `/home/box/agent-data/shared/sc-reference/guide-to-tapering.txt`

## Rules
- Build strength ≥4 weeks before tapering.
- Start taper ~2-3 weeks before first competition day; ~2-week taper ending ~5 days before first event.
- Cut total volume (sets × reps × load) **gradually** by **40-60%** (heavier athletes closer to 60%). Don’t dump it all at once.
- Keep intensity the same or ≤5-10% lower.
- Power: usually keep 3-4 sets; advanced heavy power can cut volume too.
- More rest (often +1-2 min). No new exercises. No high-eccentric / long-TUT work.
- Keep core and shoulder-health work.
- Track volume: sets × reps × weight (each limb separate for unilateral).
- Final lift (~5 days out): primary 2-3×2-4; secondary 1-2×3-5.
- Stop S&C ~5 days before first event.
