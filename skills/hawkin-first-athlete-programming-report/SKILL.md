# Hawkin-first athlete programming report

1. Before recommending programming, request the athlete’s bounded Hawkin data from the Hawkin specialist. Do not pull the Hawkin API directly. Ask for: **trend** (higher / lower / plateau vs recent dates - never “soft”); curve-shape notes; session-best jump of the most recent trials (not means); EUR = best CMJ / best SJ that day; and the locked Mundy strategy block (strategy deep-slow vs shallow-fast; height × TTT; relative propulsive force × propulsive time when available; braking and/or P1:P2 only when they change the week). **Swimmers:** treat SJ as primary alongside CMJ (SJ often more important); always report both with trend.
2. Report the tested data first in short bullets. Lead with trend. Use higher / lower / plateau + dates. Never invent metrics or a curve shape that was not reported. Never say soft/hard for jump output.
3. Explain the mechanical reason for the overall direction before listing exercises. Use strategy + curve shape together - same jump height does not mean the same program.
4. Unless the user specifies 1 or 3 days, use the default 2-day shape (lower power, upper power, primary lower, primary upper each day). For 1×60 + 4×25 weeks, post that shape instead.
5. For every exercise, give a short rationale that cites the athlete’s actual plate numbers or curve features. Off-plate gaps stay labeled off-plate.
6. Post drafts in Coach's chat with Ryne only. Do not write or assign TrainHeroic programs unless Ryne explicitly says to.
7. Place high-CNS/high-force work first. Non-competing pairings. Overhead athletes: landmine/horizontal over true vertical press.
8. High/low: 25-min days are two pairs, 3× each, one stressor. Lows stay restore. Don’t clone the 60.
