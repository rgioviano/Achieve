# Ryne programming style

Write or review Achieve programs the way Ryne’s TrainHeroic FULL exports actually look. Do not invent generic S&C. Full briefing lives at `/workspace/trainheroic-programs/ryne-programming-style.md` (summary: `style-summary.txt`). Re-read those if unsure.

## Always classify the client first
- Level: Beginner / Intermediate / Advanced (from how *he* programs, not a textbook).
- Type: sport athlete vs general. Sport is almost never in the files — ask if unknown. Do not guess from SMR block names (`SMR - Swimming` is a foam-roll block, not a swim ID).

## House session (default 2x/wk athlete)
A Prep/SMR → B Breathing (often drop on Day 4) → C Movement Prep → D1/D2 jump + med ball → E1/E2 squat/lunge + pull → F1/F2 hinge + push (Day 4 often swaps the two strength pairs) → G1–G3 core/PRI triple → H 1×5 belly lift or 90/90.

Never write “superset.” The number is the pair. Max cluster is 3. 4-week block, same exercises; progress hold time or fill blank loads (`15, _ , _ lb`). Default days 1+4; denser weeks 1/3/5.

## By level (what HIS files change)
- **Beginner:** seated/low-amplitude jumps; eccentric goblet/heel-lift; cable; TRX ISO; 3×8/3×10. No cleans, almost no trap bar/SSB/%.
- **Intermediate:** stand the jump up; trap bar, landmine, chin-up, 2/3-pt row; some 4×6. Bike only as a late G/H/I finisher.
- **Advanced:** hang clean + MB; SSB; BB RDL; GHD; For Speed / Concentric; 3×5/3×3/4×5. PRI labels written out. Bike disappears.

## Special templates (rare, named)
HVPT (throws + For Speed %); Taper (triples + Concentric + a Rest slot); Contrast Isometric (overcoming ISO → jump → throw); Land Athlete SMR + Dynamic + sprint start + hang clean.

## Language
1/2 Kneeling, Split Stance, Feet/Shoulders-Elevated, Off Box/Supports, Modified All Fours Belly Lift, 90/90 Hip Lift, Patho PEC, Left AIC/Right BC, Prep, Movement Prep. Intent lives in the name (Eccentric, ISO Hold, For Speed, Deadstop, Heel Lift).

## Do not
Rest times, 3-1-1 tempo, RPE/AMRAP/EMOM, French contrast, back squat as a staple, weekly exercise swaps, sport in the title, % on normal blocks, isolation finishers, bike as the opener.
