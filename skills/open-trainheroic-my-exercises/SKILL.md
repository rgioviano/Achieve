# Open TrainHeroic My Exercises

**When:** Locating Achieve’s team-added exercise library in TrainHeroic (for export, lookup, or review). Never use stock TrainHeroic exercises.

**Assumes:** Signed in to Achieve coach Chrome on this computer (Coach Gioviano / RG). Do not enter credentials. If signed out (login at marketplace.trainheroic.com), stop and request a sign-in handoff - never invent exercise rows.

## Steps

1. Open coach home if needed: `https://coachapp.trainheroic.com/`
2. Click **Library** in the left nav (folder icon). Lands on `https://library.trainheroic.com/` (Programs tab by default; filter often shows My Programs).
3. Click the **Exercises** tab in the top library tabs (Programs | Sessions | **Exercises** | Circuits | Prescriptions | More).
   - Direct URL: `https://library.trainheroic.com/exercises`
4. **Required filter:** At the top of the list, ensure the dropdown is set to **My Exercises** (not All Exercises / stock TrainHeroic). Ryne rule: always My Exercises only - never include stock TrainHeroic exercises in any export or list.
5. Confirm the list is team customs:
   - Heading shows **My Exercises**
   - Pagination like `1-100 of N` (demo had ~1668; use live count)
   - Columns typically: checkbox, thumbnail, Title, Type, Video, Points of Performance, Suggested Swaps, Tags, Created By
   - Created By shows Achieve team (e.g. Ryne Gioviano / The Achieve T…)
6. Rows per page can be 100. Paginate through all pages when exporting the full library.

## Visible fields to capture on export

Pull every My Exercises row with whatever is visible: Title, Type, Video (link/presence), Points of Performance, Suggested Swaps, Tags, Created By, and any other visible fields (notes, equipment, muscle groups, media URLs when opening a row). Do not invent exercises that are not in the list.

## Do not

- Switch to All Exercises or include stock TrainHeroic exercises
- Create, edit, or delete exercises unless Ryne names the exercise and explicitly says to
- Write or assign programs (that is Strength Coach / Programming)

## Report (when used for export)

Exercise count, sheet URL (or destination), and any failures (login, missing fields, caps).
