# Force Plates → Programming Decisions: Jump Data Brief (Achieve Sports Performance)

**Facility context:** Achieve Sports Performance (Aurora IL) — S&C facility using Hawkin Dynamics force plates; swim dryland + high-school athletes.  
**Purpose of this brief:** Actionable rules for when plate metrics should change **exercise selection, intensity/volume, plyometric vs strength emphasis, unload vs push, and return-to-play / in-season calls**. Measurement methods are included only where they gate a programming decision.  
**Date:** 2026-10-02 (America/Chicago)

---

## 1. Title + purpose (programming decisions only)

This brief answers one question: **Given CMJ / SJ / DJ force-time data on Hawkin, what should change in the next block of training?**

It does **not** re-teach general S&C periodization. It maps verified force-plate signals (shape, phase strategy, RSI/RSI-mod, EUR/ES:C, asymmetry, fatigue trends) to if→then programming calls, cross-checked against peer-reviewed literature and trusted practitioner sources (Kahook/Cressey, Mundy FTO, VALD, Hawkin). Achieve house practice is labeled and verified against the lit — not invented as evidence.

## 2. Methods / how to read this brief

**Research process**
1. Web search + fetch of key papers and public practitioner guides (Claudino, Gathercole, McMahon/Comfort, Bishop, Hughes-related RSI, Van Hooren, McGuigan, Labban ACLR meta, Kahook/Cressey CMJ series, VALD EUR & RSI-mod, Hawkin SJ vs CMJ).
2. Cross-check against Achieve local skills: CMJ shape classification (Kahook/Cressey), Mundy equifinality/strategy, Mundy FTO metrics, Mundy fatigue decision tree, Hawkin-first programming report.
3. Prefer prescription/dosing rules over lab methods. No invented citations.

**How to use findings**
- **Shape + strategy first** for exercise selection (Kahook: “shape is king”; Mundy: same height ≠ same program).
- **Trends (higher / lower / plateau + dates)** for unload vs push and in-season load — never “soft/hard.”
- **Relative force (per BM)** over absolute when body mass differs (Mundy FTO; Sole et al. relative magnitude emphasis).
- **Asymmetry as a separate flag** — do not collapse into “fatigued” (Mundy fatigue tree; Bishop).
- **Thresholds are population-specific** (Mundy). Use Achieve local baselines; do not copy universal % cutoffs as gospel.
- **Swimmers:** treat **SJ as primary alongside CMJ** (often more important for concentric “from still” force) — house practice aligned with Van Hooren (SJ = rapid force without countermovement) and Hawkin (SJ ≈ true force production / acceleration ability).

**Language standard (Achieve)**
- Report: *higher / lower / plateau* vs named dates.  
- Ban: *soft / hard* for jump output.  
- Cite session-best (or clearly labeled mean) under fixed protocol; do not mix flight-time vs impulse-momentum height methods without labeling.

## 3. Findings by topic (with citations)

### 3.1 CMJ phases and why they change the program

McMahon, Suchomel, Lake & Comfort (*Strength Cond J*, 2018) define six phases from the force-time record: **weighing → unweighting → braking → propulsion → flight → landing**. Programming relevance:

| Phase | What it tells you | Programming lever |
| --- | --- | --- |
| Unweighting | How fast/hard they unload (peak negative COM velocity scales with unweighting impulse) | Faster get-down cues / drop-squat jumps if unweight is slow — **not** slow eccentrics if brake is already good |
| Braking | How they stop the COM (tall-thin vs short-fat impulse; braking RFD) | Catch quality, yielding holds, drop-and-stick **when brake quality is poor**; **skip** long-ecc / altitude landings when brake is already good |
| Propulsion | How they reaccelerate (early vs late force organization; relative propulsive force × time) | Magnitude overload vs transition/iso work vs velocity-assisted plyos — driven by **curve shape** |
| Landing | Separate from push asymmetry; absorption strategy | Landing-specific work / RTP gates (especially post-injury) |

Kahook (via Cressey Parts 1–2) and McMahon et al. both emphasize: **do not program from jump height alone**. Phase shape and timing diagnose *how* force is produced.

**Achieve verification:** House rule “shape is king; metrics track trends” matches Kahook Part 2 explicitly and McMahon practical applications (“understand what the shape of the force-time curve means”).

### 3.2 Force-time curve shape archetypes → exercise direction

Kahook’s seven propulsive-phase archetypes (Cressey Part 2) are the primary **exercise-selection** map:

1. **Early Peak Unimodal** — Efficient SSC; limiter = **magnitude**. Raise amplitude, narrow TTT. Concentric overload, reactive, weighted jumps, depth jumps when GCT stays short.
2. **Late Peak Unimodal** — Low braking RFD; longer TTT. Train **braking RFD** (drop catch, progressive plyos), not max strength alone. If unweight is the real limiter and brake is fine → faster drop, not slow eccentrics.
3. **Early Peak Bimodal** — High braking RFD + mid-push coordination cost (second peak / dip). Transition work: ballistic/overcoming isos at hang position; light/assisted jumps; faster get-down **without digging deeper**.
4. **Late Peak Bimodal** — Coordination **plus** capacity; **low braking RFD by definition**. Brake *time* can look “fine” while stop is weak. Train catch (yielding hold / drop-and-stick) + faster drop if unweight slow. **Do not skip braking work.**
5. **Early Peak Plateau** — Early spike then flatline at braking→propulsion hang. First pick often **quarter-squat Split Squat ISO Push** (match iso to hang), then light jump / assisted SSC.
6. **Late Peak Plateau** — Flat then late peak; capacity + coordination. Fundamentals first; low contact volume; yielding isos; long horizon for pattern change.
7. **Plateau (no single spike)** — Efficient but magnitude/duration limited. Same menu as Early Peak Unimodal: taller/narrower curve.

**Inconsistent (Achieve add-on):** Trial-to-trial shape disagreement → motor control / consistency first; low contact quality work; do not escalate plyo intensity.

**Lit alignment:** Sole et al. (*J Strength Cond Res*, 2018) — higher jumpers show greater **relative** magnitude/impulse in positive-force (stretching/braking and propulsion) phases, not necessarily different phase *durations*. Supports targeting force organization, not “make the squat deeper/slower” as a default.

**Achieve locked rules verified against Kahook:**
- Early Peak Bimodal / mid-push dip → quarter-squat Split Squat ISO Push → light jump; faster get-down without digging deeper. **Supported** (Kahook early bimodal/plateau: coordination at peak braking; Achieve iso-position match).
- Late Peak Bimodal: brake time alone ≠ good stop → train catch; don’t skip braking. **Supported** (Kahook late bimodal = low braking RFD + coordination).
- If braking actually good → don’t add long-ecc / yielding brake builders / altitude landings. **Supported** (Kahook early-peak efficient shapes; McMahon: braking strategy is force×time tradeoff — don’t lengthen what is already tall-thin).
- Depth jumps only when shorter-stiffer bounce is shown; **not** for Early Peak Bimodal deep-slow. **Supported** by RSI/DJ literature below (optimal RSI / short GCT prerequisite) and Kahook (early bimodal needs transition efficiency, not more eccentric depth).

### 3.3 Equifinality / strategy (height × TTT; relative force × time)

Mundy (FTO / equifinality series) and Linthorne (*Am J Phys*, 2001): same jump height can hide **deep-slow / lower force / longer propulsion** vs **shallow-fast / higher force / shorter propulsion**. Impulse alone collapses force and time.

**Programming implication:** Prefer views that keep components visible:
- Jump height × time to takeoff (TTT) / contraction time
- Relative average propulsive force × propulsive time
- P1:P2 propulsive impulse index when early vs late propulsion split matters

**Achieve:** Relative force over absolute when BM differs — aligned with Mundy FTO and Sole et al. relative magnitude findings.

### 3.4 Braking vs propulsive impulse; RFD

- Braking net impulse must match unweighting net impulse (McMahon et al., 2018) — strategy is **tall-thin (high force, short time)** vs **short-fat**.
- Propulsive impulse (esp. relative) relates closely to jump height; early vs late organization changes exercise choice (Kahook shapes; Mundy P1:P2).
- **RFD caution:** Many CMJ eccentric/concentric RFD metrics show poorer reliability than height, impulse, peak force, or phase times (e.g., Merrigan et al. reliability work on CMJ/IMTP force-time metrics; Gathercole notes strategy variables can be more useful than noisy RFD). Use RFD for programming only when reliable for *that* athlete/setup; prefer braking peak relative force, brake time, force at zero velocity, and curve shape when RFD is noisy.

### 3.5 SJ vs CMJ; EUR / ES:C (especially swimmers)

**Mechanisms (Van Hooren & Zolotarjova, *J Strength Cond Res*, 2017):** CMJ > SJ is driven mainly by **uptake of muscle slack + buildup of stimulation** during the countermovement; elastic energy is a smaller contributor. A **larger** CMJ−SJ gap is **not always better** — it can mean weak SJ (poor pretension / slow stimulation) rather than “great SSC.”

**EUR (McGuigan et al., *J Strength Cond Res*, 2006; VALD 2026 guide):** EUR = CMJ height / SJ height (or peak power variants). Varies by sport and training phase. VALD: **never program from EUR alone** — pair with absolute/relative jump heights (quadrant view). High EUR + low heights → capacity problem. Low EUR + high heights → may be sport-specific concentric strength, not a mandatory plyo prescription.

**Hawkin (Berberet):** SJ ≈ true force production from still / acceleration ability; CMJ ≈ energy transfer / SSC. Software rejects SJ trials with >5% below-BW countermovement — critical for valid EUR.

**Swim dryland house practice:** Treat **SJ as primary alongside CMJ (often more important)** — **verified** against Van Hooren (SJ capability critical when little time for large countermovement; starts/pushoffs) and Hawkin’s framing of SJ as concentric force from zero. EUR still useful as a **pointer**, not a solo decision metric.

**Practical EUR/ES:C rules (cautious):**
- Low EUR + low SJ → build concentric/SJ capacity and pretension under time pressure; don’t only add slow CMJ plyos.
- Low EUR + high SJ/CMJ → may leave alone or bias reactive/SSC if sport needs it.
- High EUR + low both → strength/power capacity first.
- Achieve reporting: EUR = best CMJ / best SJ that day (session-best continuity).

### 3.6 RSI / RSI-mod and drop jumps

- **RSI (DJ)** = jump height / ground contact time. Interday reliable with incremental drop heights; use to find **optimal drop height (ODH)** (Byrne et al., *J Strength Cond Res*, 2017 — RSI & ODH ICC ≥ 0.80; Markwick et al., 2015 for RSI reliability).
- Training from individual optimal RSI height outperformed fixed 30 cm in youth soccer (Ramírez-Campillo et al., *J Strength Cond Res*, 2018).
- **RSI-mod (CMJ)** = jump height / contraction time (VALD). Same height with longer TTT = lower RSI-mod → strategy/fatigue signal (Gathercole-aligned). Always inspect numerator and denominator separately (VALD).
- **Programming gate:** Depth / reactive high-intensity only when athlete shows **short-stiff bounce** (acceptable GCT, RSI/ODH profile). Do **not** prescribe high depth jumps for Early Peak Bimodal athletes who are deep-slow or mid-push dipping — they need transition quality first (Kahook + RSI prerequisites).

### 3.7 Fatigue monitoring / trends (higher–lower–plateau)

**Claudino et al. (*J Sci Med Sport*, 2017) meta-analysis (151 articles):** Average CMJ height more sensitive than single best jump for detecting fatigue and supercompensation; peak/mean power, peak velocity, peak force, impulse also track supercompensation. *(Note: Achieve often uses session-best for programming shape — for fatigue monitoring, prefer consistent method; if using best, demand multiple trials and trend over dates, and consider averaging for NMF dashboards.)*

**Gathercole et al. (*Int J Sports Physiol Perform*, 2015):** Typical outcome metrics may miss fatigue; **strategy** variables (force at zero velocity, durations, force–velocity area, mean power, peak velocity) change meaningfully. At 72 h, time-related variables can still be elevated vs baseline even as height recovers — **altered strategy** ≠ recovered.

**VALD RSI-mod:** Fatigue often shows as same/near height with longer contraction time (worse RSI-mod).

**Mundy fatigue tree:** One quality CMJ → outcome → phase strategy → fatigue vs adaptation vs noise → action. Thresholds population-specific. Asymmetry separate. Reliability is a condition of use. Multidimensional context (Rebelo et al., *Sports Med*, 2026 as cited by Mundy) — plates alone ≠ full readiness.

**Achieve unload rule (verified):** Unload jumps when **CMJ lower + mid-push dip + slow TTT/unweight** → quality contacts, not high-volume reactive. Aligns with Gathercole (strategy fatigue) + Kahook early-bimodal stress + Claudino (height drop as signal).

**Language:** higher / lower / plateau with dates — not soft/hard.

### 3.8 Asymmetry (push vs landing)

**Bishop et al. (*Strength Cond J*, 2018):** Use correct formula — bilateral tests: BAI-1 / SI relative to **sum**; unilateral: BSA or % difference. Asymmetry is “real” only if > within-limb variability (CV); track longitudinally; task-specific (Bishop et al., *J Strength Cond Res*, 2021 — side often disagrees across tests).

**Programming:** Targeted unilateral strength/plyos matched to test direction can reduce jump asymmetries (meta evidence for unilateral plyometrics). Do **not** auto-prescribe from a 10–15% myth threshold without reliability and individual baseline (Bishop reviews: clear injury-risk cutoffs remain weakly supported).

**Push vs landing:** Treat as separate flags (propulsive impulse asymmetry ≠ landing peak force asymmetry). Post-ACLR lit shows concentric (push) asymmetries often dominate CMJ at RTS while DJ shows eccentric + RSI deficits (Kotsifaki; Labban et al., 2024 meta; Sportsmith/Maree synthesis).

### 3.9 In-season vs RTP gates

**In-season (healthy HS / swim dryland):**
- Maintain protocol continuity (hands-on-hips preferred for lower-body isolation — Kahook Part 1; McMahon).
- Use trend language: if CMJ/SJ/RSI-mod **lower** vs recent dates **and** strategy worsens (longer TTT, mid-push dip, slower unweight) → **unload** intensity/volume of jumps; keep quality.
- If metrics **plateau** at acceptable levels → maintain; don’t chase noise.
- If **higher** with clean shape → can push intensity or complexity carefully within competition constraints.

**RTP / post-ACLR (Labban et al., *J Exp Orthop*, 2024 meta; Kotsifaki/Sportsmith practitioner synthesis):**
- Discriminative: CMJ jump height ↓; concentric/eccentric **impulse asymmetry** ↑; DJ involved limb ↓ eccentric peak vGRF, uninvolved ↑; RSI/contact-time deficits on DJ.
- Plates are a **battery**, not a single pass/fail. Combine with strength LSI, hop tests, movement quality, medical clearance.
- Practitioner discharge-style targets often cited (illustrative, not Achieve medical policy): CMJ height ~90% LSI or pre-op; concentric/eccentric impulse asymmetry <10%; landing peak force asymmetry <15%; DLDJ RSI examples >1.3 m/s — **use local norms and clinician oversight**.
- Rehab programming maps deficits: concentric impulse/height → explosive concentric + calf/toe-off; eccentric/landing → drop catches; RSI/GCT → graded reactive (pain/swelling gated).

**Achieve stance:** Force plates inform S&C programming and readiness flags; they do **not** replace medical RTP clearance.

## 4. Programming decision rules (actionable if→then)

### Shape / exercise selection
1. **IF** Early Peak Unimodal or clean Plateau **THEN** emphasize magnitude: concentric overload, weighted jumps, reactive circuits; depth jumps OK if GCT stays short.
2. **IF** Late Peak Unimodal **THEN** prioritize braking RFD (drop catch, progressive plyos); add faster unweight only if unweight time is the limiter.
3. **IF** Early Peak Bimodal / Early Peak Plateau (mid-push dip or hang) **THEN** quarter-squat Split Squat ISO Push (or matched-position ballistic iso) → light/assisted jump; cue faster get-down **without** deeper countermovement; **avoid** high depth jumps until bounce is short-stiff.
4. **IF** Late Peak Bimodal / Late Peak Plateau **THEN** train catch (yielding hold / drop-and-stick) + capacity; do **not** call braking “fine” from brake time alone; lower contact volumes, quality first.
5. **IF** braking quality already good (early-peak efficient shape + short brake with strong stop) **THEN** do **not** add long-ecc squats, deep yielding “brake builders,” or extra altitude landings for braking.

### Strategy / metrics
6. **IF** same height with longer TTT / lower RSI-mod / lower relative propulsive force **THEN** train strategy (faster intent, shallower efficient CM, transition), not “more jump height volume.”
7. **IF** comparing athletes or days with different BM **THEN** use relative force metrics, not absolute peak force rankings.

### SJ / EUR (swimmers especially)
8. **IF** swimmer or start/pushoff-dominant athlete **THEN** program from **SJ trend + CMJ trend**; SJ often primary.
9. **IF** low EUR driven by weak SJ **THEN** concentric/SJ capacity + pretension under time pressure — not only CMJ plyometrics.
10. **IF** high EUR but both jumps low **THEN** strength/power capacity first (VALD quadrant logic).

### Plyometric vs strength emphasis
11. **IF** RSI/ODH profile shows short GCT and rising RSI at chosen drop height **THEN** emphasize plyometric/reactive intensity at/near ODH.
12. **IF** deep-slow CMJ or Early Peak Bimodal without short-stiff DJ **THEN** strength + transition/iso + low-level quality contacts **before** high-intensity depth jumps.

### Unload vs push (fatigue / in-season)
13. **IF** CMJ (and/or SJ) **lower** vs recent dates **AND** mid-push dip **AND** slow TTT/unweight **THEN** unload jump intensity/volume; quality contacts only; reduce reactive density.
14. **IF** height recovered but time/strategy metrics still worse (Gathercole pattern) **THEN** treat as incomplete recovery — do not fully restore high-CNS plyo load yet.
15. **IF** metrics **higher** with stable/improving shape **THEN** progressive overload OK (intensity or complexity).
16. **IF** **plateau** within normal noise **THEN** maintain; avoid reactive chasing.

### Asymmetry / RTP
17. **IF** propulsive (push) asymmetry is real (>CV) and persistent **THEN** targeted unilateral strength/plyo in the tested direction; retest same task.
18. **IF** landing asymmetry elevated but push OK **THEN** landing/absorption emphasis — do not assume same fix as push asymmetry.
19. **IF** RTP context **THEN** require medical clearance + multi-test battery (CMJ/DJ height, impulse asymmetries, RSI/GCT, strength); plates inform deficits and progress, not solo clearance.

## 5. Caveats / limits

- **Shape classification** (Kahook) is practitioner-validated pattern language, not a multi-lab RCT taxonomy — use consistently within Achieve, recheck over weeks before hard program pivots.
- **Mundy FTO / fatigue tree** are coaching frameworks (2026 series); numeric thresholds must be **local**.
- **RFD** and some eccentric metrics: reliability often insufficient for hard cuts — prefer shape, impulses, phase times, RSI-mod components.
- **EUR cutoffs** (e.g., 1.1) are context-blind without absolute heights and sport (VALD; Van Hooren: larger gap ≠ better).
- **Asymmetry → injury** causal thresholds remain weakly supported prospectively (Bishop reviews); track individually.
- **Claudino** favors average height for NMF; Achieve session-best for shape — be explicit which you use for which decision.
- **Swim-specific** plate→program RCTs are sparse; SJ primacy is mechanistic + practitioner inference, not a swim-only meta.
- Force plates measure COM kinetics, **not** joint/MTU behavior (McMahon et al.).
- RTP numbers in practitioner articles are examples — not Achieve medical policy.

## One-page decision rules (for Hawkin)

1. **Shape first, metrics for trends** — classify session-best CMJ shape; use higher/lower/plateau + dates (never soft/hard).
2. **Early Peak Bimodal / mid-push dip** → quarter-squat Split Squat ISO Push → light jump; faster get-down, not deeper squat; no high depth jumps yet.
3. **Late Peak Bimodal** → train the catch; brake time alone ≠ good stop; don’t skip braking work.
4. **Braking already good** → do not pile on long-ecc / yielding brake builders / altitude landings.
5. **CMJ lower + mid-push dip + slow TTT/unweight** → unload jump load; quality contacts only.
6. **Swimmers** → SJ primary alongside CMJ; always trend both; EUR only with absolute heights.
7. **Relative force > absolute** when BM differs; prefer height×TTT and relative propulsive force×time over impulse alone.
8. **Depth/reactive high intensity** only when RSI/GCT shows short-stiff bounce; else strength + transition first.
9. **Asymmetry** = separate flag (push ≠ landing); act if > trial CV and persistent; match unilateral work to the test.
10. **In-season** — lower + worse strategy → unload; higher + clean shape → push carefully; plateau → maintain.
11. **RTP** — plates diagnose deficits (height, impulse asymmetry, DJ RSI/vGRF); never sole medical clearance.
12. **Same jump height ≠ same program** — deep-slow vs shallow-fast need different emphases (equifinality).
