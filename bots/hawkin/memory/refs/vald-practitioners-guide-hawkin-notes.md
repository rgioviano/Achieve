## Key frameworks

- **Data informs decisions; it does not make them.** Collecting plate data ≠ using it. Ask: what does this tell you about the athlete, and what will you do differently? (Goodin quote, p.2)
- **KPIs as checkpoints.** CMJ, DJ, and sprint acceleration metrics are proxy KPIs used to estimate improvement in determinants such as lower-body power (p.13).
- **Profiling vs monitoring (p.15 — primary plate framework):**

  | Type | Purpose | Cadence | Metric selection (examples) |
  |---|---|---|---|
  | **Profiling** | Maximal physical capacities → inform future program design | Periodic | Metrics strongly tied to a quality (e.g., peak force, sprint time, **jump height**) |
  | **Monitoring** | Current neuromuscular status → readiness + acute fatigue response | Frequent | Sensitive metrics (e.g., **RSI-Mod**, **contraction time**, **asymmetry**) |

- **Load vs load-response (p.34–35):**
  - *Load monitoring* = work done (volume, sprint distance, exposure).
  - *Load-response monitoring* = how the athlete responded (fatigue, readiness, adaptation). Example: CMJ on ForceDecks the day after training = load-response, not load itself.
- **Internal vs external load (p.35):** external = work completed; internal = physiological/perceptual response. Same external load can produce different internal responses. Whether a metric is “load” or “response” depends more on the *question* than the device.
- **Needs analysis (p.16):** compare athlete profile to sport demands / benchmarks / **VALD Norms** percentiles to direct training at KPIs most likely to impact performance. Norms are referenced conceptually only — no plate-specific tables in this PDF.
- **Fitness–Fatigue + GAS (p.15):** underpin modern monitoring; performance = balance of fitness adaptation vs temporary fatigue.
- **Simplify metrics (p.54–55):** more data ≠ better decisions. Prefer a small KPI set aligned to qualities and decisions. Example Hub dashboard (Sean Baker): ForceDecks **RSI-Mod (CMJ)** as the plate KPI (alongside ForceFrame hip add:abd and NordBord relative eccentric PF — non-plate context only).

## Decision rules (metric → action)

Rules stated or clearly implied in the PDF only:

1. **Jump height stable, but RSI-Mod or braking RFD changing meaningfully** → consider starting a **DUP or WUP** cycle to rebalance weekly workload so multiple qualities are maintained (ForceDecks / CMJ; p.41).
2. **Power limitation typing via CMJ / DSI (p.50–51):**
   - High force production + low jump height → prioritize velocity / ballistic development intent.
   - High jump height + relatively low force → prioritize force-production development.
   - **DSI profiling** → identify whether *maximal* vs *ballistic* force production is the greater limitation → prioritize exercise selection, loading, and intent accordingly.
3. **ForceDecks CMJ: reduced force production despite acceptable jump height** → treat as a **strength / force-production** limitation to address in programming (p.48).
4. **When meaningful adaptations are no longer achieved** (supported by ForceDecks / VALD suite) → prescribe temporary workload reduction / **deload** (p.40).
5. **If monitoring causes frequent priority flips** → likely the overall workload/structure is failing to produce intended adaptations — fix the plan, don’t over-react session-to-session (p.32).
6. **HSR (heavy-slow resistance) + plyometrics together** → greater jump-performance gains than either alone; either alone typically ~**2–7% jump height** over **6–12 weeks** (p.23). Use combined stimulus when jump/power is a target.
7. **SSC contact-time split for exercise selection (p.13):** slow SSC **>250 ms GCT**; fast SSC **<250 ms GCT**. Both can improve RFD, neural drive, lower-limb stiffness — individualize intensity/workload.
8. **Session sequencing:** explosive/plyometric work early (ascending order: high-velocity → heavy strength) before fatigue (p.45–46). Aligns with using early-session CMJ/DJ as both monitor and stimulus.
9. **Rams-style individualization (p.56):** shared team framework → then modify exercise selection / loading / emphasis from ForceDecks strength- vs power-dominant profiles (~60–70% roster got some individualized modification in that case study).

## Programming implications from plate data

- **Strength (p.48–50):** plates/dynamometers identify strength limitations; progress intensity first, then volume; objective monitoring helps decide when to progress (avoid premature overload or delayed progression). Resistance fatigue can depress performance **12–72 h** post — relevant when interpreting next-day CMJ.
- **Power (p.50–52):** plates distinguish force- vs velocity-driven power limits (see decision rules). Methods: Oly variations, loaded jumps, ballistic RT, med-ball throws, accelerative-intent RT. Slow/higher-impact plyos (loaded CMJs, hurdle jumps, higher DJs) emphasize force/peak power; combining slow + fast plyos increases power adaptations.
- **Reactive strength (p.53):** DJ, hops/bounds, pogos, sprinting, fast-SSC plyometrics. Use plate RSI/RSI-Mod/contact time/jump height/strategy to check SSC function.
- **Specificity — kinetics targets (p.17):** force production, **braking ability**, **RFD**, **impulse**.
- **Sprint/HSR interference (p.18):** excess HSR without enough sprinting may reduce max speed; isometrics (e.g., run-specific isometric series) as adjunct; monitor with ForceDecks (among other tools) to confirm positive change without negative adaptations.
- **Point A → Point B education (Hocevar, p.3):** use plate metrics (speed, vertical jump, RFD, RSI, etc.) vs standards/goals to show the gap training will close.

## Testing / protocol notes

- **Integrate testing into sessions** rather than always needing dedicated test days (p.46–48):
  - **Session entry:** **3 CMJs** immediately after a structured warm-up.
  - **Within session:** isometric/eccentric biofeedback (ForceFrame/NordBord Training Mode — non-plate, but same “intent vs target” idea).
  - **Substitution:** maximal isometric (e.g., seated ankle PF) in place of a set — data + stimulus.
  - **Session exit:** repeat assessment for **acute neuromuscular response** (interprets fatigue/response, not fresh capacity).
- **Early-session DJ/CMJ** can monitor fatigue *and* provide an adaptive power stimulus; **IMTP / isometric squat** can add PAPE + strength benchmark (p.47).
- **ForceDecks Group Testing** — rapid group assessments for efficient, consistent collection (caption, p.47).
- **Warm-up consistency (p.48):** similar setup/execution required to detect change. **RAMP** (raise, activate, mobilize, potentiate) popular; guide suggests integrating testing **after mobilize, before potentiate** so neuromuscular status is assessed without potentiation influence.
- **Fatigue confounds (p.48):** end-of-session testing ↓ performance — useful for *response* questions; **consistent fatigued testing confounds** performance/capacity data.
- **Environment (p.48):** team-sport training environments often inflate scores (encouragement/competition) — consider when comparing to quiet/clinical settings.
- **Monitoring assessment traits (p.33):** minimally invasive, reliable (stable when status unchanged), sensitive (detect meaningful readiness/fatigue/adaptation change). Elite example: daily or weekly CMJ on force plates for readiness; clinical settings may use more periodic reassessment.
- **CMJ on ForceDecks repeated over time** — separates strength-speed vs speed-strength / starting-strength improvements (e.g., loaded squat power ↑ vs vertical jump ↑) (p.53).
